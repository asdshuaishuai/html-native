# 快速上手

> 教程细节见 [getting-started.md](../getting-started.md); 本页是最短路径。

## 1. 构建

```bash
git clone https://github.com/asdshuaishuai/html-native && cd html-native
bash tools/build-daemon-cli.sh          # daemon + hn CLI
ZIG=zig bash tools/build-multiplatform.sh   # 全平台产物 → dist/
```

要求: C 编译器(cc/clang); 交叉构建要 zig; QuickJS/FreeType 走
homebrew(缺省降级仍可构建核心)。

## 2. 第一个窗口

写 `hello.html`:

```html
<html>
<head>
  <meta name="hn-window" content="360x220">
  <meta name="hn-theme" content="dark">
  <style>
    body { margin: 0; display: flex; align-items: center;
           justify-content: center; background: #101828; }
    h1   { font-size: 22; color: #7fd1ff; }
  </style>
</head>
<body><h1>Hello, Neb</h1></body>
</html>
```

开窗(免单位数值合法, 引擎自动补 px):

```bash
dist/hnapp-macos-arm64 hello.html
```

## 3. 加交互

```html
<div id="out">…</div>
<button hx-get="sys://cpu" hx-target="#out" hx-trigger="click">查 CPU</button>
```

`hx-*` 由运行时解释(零网络; `sys://` 是本地系统桥)。JS 可选:
`document.querySelector('#out').textContent = '…'`。

## 4. agent 路线

```bash
dist/hn-daemon &
dist/hn open card hello.html      # 或 cat xxx.html | dist/hn open card -
dist/hn list                      # 运行中的应用
dist/hn update card hello2.html   # 热更新(窗口不动)
dist/hn close card
```

## 5. 无头渲染(agent 感知 / CI)

```bash
dist/hncore-macos-arm64 render hello.html out.png 360 220
dist/hnapp-macos-headless hello.html --probe     # 管线自检
```
