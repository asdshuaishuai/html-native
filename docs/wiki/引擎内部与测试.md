## 一帧流水线

```
事件/帧钟 → hn_rt_frame
  ① 级联 hn_style_compute_all    选择器匹配+继承(级联记忆化跳过未变节点)
  ② details/透明背板等级联后改写
  ③ 布局 hn_layout_root          整树键刷新 → block/flex/IFC(子树布局记忆跳过未变子树)
  ④ 绘制 hn_paint_root           DOM → 14 种绘制指令(静态子树片段回放)
  ⑤ 动画 hn_context_anim_tick    过渡/@keyframes/Lottie/网格/入场退场
  ⑥ 呈现                         hnsoft / cairo / Metal 消费同一显示列表
```

## 内存纪律

- **文档 arena**: DOM/文本随文档生灭, 无 free; 换文档 = 整区释放。
- **tmp arena**: 每帧重建; 指令引用的副本生命周期 = 本帧。
- **runs**: 挂节点跨帧存活; wipe-once 帧代数管理("谁重建谁清")。
- **缓存族**(Lottie/GIF/片段/测量/级联): 各有明确失效点, 文档替换全清。

## 确定性承诺

- 跨架构布局输出**逐字节一致**(交叉产物直接 diff);
- 动画时钟 1/64ms 栅格量化, 事件在到达时刻应用 —— 跨帧率重放一致;
- 优化层"命中"语义 = 逐位一致 或 ≤1ulp 平移等价(探针双跑对照钉住)。

## 探针门禁(42 族, ~1300+ 断言)

```bash
bash tools/<主题>_probe.sh        # 单族
# 主题: render css html layout canvas dom events anim timer fmt md include
# stream lottie three quad3d mesh live2d cubism gif media media_element
# media_window gpu hidpi pet window resident perf sysbridge sysroute http
# project pack capsule capsule_app wasm pe_surface neb3_fallback
# canvas_backend cubism_mask hnsoft_alpha macos_deep freeze_l2 linux_parity
```

纪律:
1. 探针失败即退出非零, **全量绿 = 可交付**;
2. 优先用 `dist/hncore-<os>-<arch>`(陈旧 /tmp 副本有告警);
3. 优化必须带"机制开/关双跑对照"(逐位 cmp 或容差);
4. 真窗探针钉副屏(`HN_WINDOW_POS`)。
