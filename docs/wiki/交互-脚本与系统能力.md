# 交互 · 脚本 · 系统能力

## hx-*(htmx 风格, 运行时解释, 零网络缺省)

```html
<!-- 点击拉系统桥, 结果换入目标 -->
<div hx-get="sys://cpu" hx-target="#out" hx-trigger="click">刷新</div>
<!-- 载入即拉 + 每 2s 轮询 -->
<span hx-get="sys://uptime" hx-trigger="load every 2s">…</span>
<!-- 表单: 回车/提交收集 name=value(urlencoded) -->
<form hx-post="sys://notify" hx-target="#tip">
  <input name="msg" placeholder="通知内容"><button>发送</button>
</form>
```

属性: `hx-get`/`hx-post`/`hx-put`/`hx-delete`/`hx-patch` +
`hx-target`(this/CSS/closest/find/next/previous) + `hx-swap`
(innerHTML/outerHTML/beforeend/afterbegin/afterend/delete/none) +
`hx-trigger`(click/load/every Ns/change/hover + delay:N/changed 修饰符) +
`hx-vals`/`hx-headers`(JSON) + `hx-include`(逗号分隔 CSS 选择器,
附加元素值进请求体) + `hx-select`(响应子树选择换入) +
`hx-confirm`(htmx:confirm 事件, preventDefault 取消)。
列表错档入场: 容器 `hn-stagger="每项ms"`(子项按序依次浮现)。
htmx:beforeRequest/afterRequest/afterSwap 事件可监听。
input 回车沿 自身→祖先→最近 hx 载体 提交。

## sys:// 系统桥(零网络零依赖)

| 路由 | 语义 |
|---|---|
| `sys://host` / `cpu` / `memory`(mem) / `disk` / `battery`(power) / `uptime` | 系统读取(返回 hn 片段, 配 hx-target 换入) |
| `sys://info` | 列全部路由 |
| `sys://open?url=…` | 交系统打开 URL |
| `sys://notify?…` | 系统通知 |
| `sys://store/get|set` | 应用级持久化 KV |
| `sys://clipboard` | 剪贴板 |

HTTP 是**注入的 transport**(非引擎能力): `hn.fetch` 与 hx-get 的
http(s) 地址走运行时网络层, `HN_FETCH_ALLOW` 白名单 +
`HN_FETCH_TIMEOUT_MS` 超时。

## 事件种类(引擎管道)

mouse 系(click/mousedown/mouseup/mouseenter/mouseleave)、keydown/keyup、
focus/blur、scroll、input/change、submit、hover + 生命周期
launch/show/hide/destroy。带 id 元素冒泡; 命中测试打在**目的地布局盒**
(动画中的元素按弹簧目的地判定, 快速连点不落空)。

## 宿主注入事件(agent 驱动)

```bash
dist/hn event card --kind click --target go
# socket: {"op":"event","id":"card","kind":"click","target":"go"}
```
