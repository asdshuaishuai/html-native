## 平台契约

宿主要实现的全部 = `platform/hn_platform.h` 的 ~15 函数(开窗/blit/
事件/时钟 `hnp_now_ms[_f]`/光标/…) + 可选媒体宿主 + 可选 GPU 原语表。
`app/hn_app.c` 是参考实现; `tools/hncore.c` 演示零 GUI 嵌入。

## 诚实边界(不承诺的事)

- **不是浏览器**: hn 子集外的 CSS/HTML 不保证; `hn pack` 的兼容性
  体检可机检逐页差异。
- 引擎核心零网络: HTTP 在运行时层且可裁剪。
- 无 Accessibility(ARIA) / 无 DevTools 窗口 / 无虚拟滚动 —— roadmap
  排期, 见 README「已知简化与路线图」。
- Live2D 官方 Core 二进制不入库(`tools/fetch-cubism-core.sh` 自取,
  商业授权走 Live2D 官方口径)。
- 已知活跃问题: ISSUES.md(gpu rect 页 parity 回归待 Metal 专项;
  media_window 视频帧断言间歇)。
